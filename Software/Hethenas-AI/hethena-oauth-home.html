Hethena AI

Hethena AI is a private desktop operations assistant for DevOps, IT operations, productivity, calendar review, and guarded email workflows.

Hethena is operated by Intranet Innovations And Services LLC and is designed for local, user-authorized workflows. Google access is used only when the user explicitly connects Gmail or Google Calendar through OAuth consent.

Google Integrations

Hethena can connect to Gmail and Google Calendar after user authorization. Gmail features include mailbox search, reading selected messages, preparing guarded drafts, and user-confirmed cleanup actions. Calendar features include checking connection status and reading upcoming agenda items.

Data Handling

OAuth tokens are stored locally on the user's computer. Hethena does not sell Google user data and does not use Google user data for advertising.
